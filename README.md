# Leonardo's Playground

A minimalist portfolio and showcase of free and open-source applications built by Leonardo. 

## Featured Projects

* **Bedrock**: High-contrast, minimalist monochrome notes editor for Android.
* **Overseer**: Modern, minimalist, and feature-packed Android file manager.
* **Anchor**: A privacy-first, offline-capable budget and expense tracker application (WIP).

## Tech Stack

This project is built using:
* React
* TypeScript
* Tailwind CSS
* Vite

## Local Development

```bash
# Install dependencies
npm install

# Start the development server
npm run dev

# Build for production
npm run build
```
